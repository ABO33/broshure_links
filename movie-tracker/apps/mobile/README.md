# Movie Tracker mobile app

The Phase 1 app is a runnable Expo Router foundation with tabs, theme primitives, Query
Client, Zustand preferences, environment validation, and test/lint/type-check tooling.

```powershell
Copy-Item .env.example .env
npm install
npm start
```

Press `a` for an Android emulator or scan the QR code with Expo Go. On Windows, use an
iPhone with Expo Go or an EAS cloud development build; the iOS Simulator requires macOS.
