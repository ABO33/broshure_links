# Product artwork placeholders

Before preview or production builds, add original PNG assets here and reference them in
`app.json`:

- `icon.png` (1024 x 1024)
- `adaptive-icon.png` (1024 x 1024, transparent foreground)
- `splash-icon.png` (at least 512 x 512)
- `favicon.png` (48 x 48)

Phase 1 deliberately does not ship copied film artwork or a misleading final brand mark.
